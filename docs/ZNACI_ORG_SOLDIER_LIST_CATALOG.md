# znaci.org — unit monographs with soldier lists

Survey of the znaci.org (Biblioteka Znaci) online library for **unit monographs that contain a spisak/popis boraca** (soldier list) we can extract from. Surveyed 2026-09-27.

## Method
Fetched every book landing page from the biblioteka index whose title mentions **brigada / divizija / odred / korpus / bataljon** (211 unit monographs total). For each, scanned the table of contents for keywords: `spisak boraca`, `popis boraca`, `spisak palih/poginulih/umrlih/preživjelih/pripadnika/nestalih/starešina`, `imenik boraca`, `register borcev`, `poimenični`.

## What this doesn't include
- Slovenian-language monographs (books whose titles are in Slovenian may not have matched the keyword regex — e.g., «poimenski register», «popolni imenski seznam»). Worth a second pass with Slovenian keywords if we want to expand the Ljubljanska-area brigades.
- Documentary source collections ("Zbornik dokumenata NOR", VII series) — those have unit muster rolls too but scattered across many volumes.
- The 20+ untracked brigade cover photos in `website/public/images/` (Cankarjeva, 14. primorsko-goranska, 16./17./18. slavonska, deseta krajiška, druga dalmatinska, etc.) — these suggest you're already prepping several of the Category A/B brigades above.
